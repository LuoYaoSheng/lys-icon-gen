多平台应用图标生成工具。

Icon Gen 用于把一张高质量图标快速生成 iOS、Android、macOS、Windows、watchOS 所需的多尺寸资源和标准目录结构。它是 lys Open Source 体系中的项目资产生成工具。

项目能力

覆盖应用发布前最常见的图标资产准备工作，重点是本地处理、结构化输出和跨平台规格统一。

多平台规格

支持 iOS、iPadOS、macOS、watchOS、Android 和 Windows 常用图标尺寸。

标准目录结构

可生成 Xcode 需要的 AppIcon.appiconset 和 Android 资源目录结构。

浏览器本地处理

Web 版使用 Canvas 在浏览器内处理图片，不上传原图，适合快速生成和临时处理。

使用入口

当前项目包含 Web 版和 Electron 桌面版。线上主入口是项目站，在线工具作为体验入口保留。

常见问题

关于 iconsize 的常见问题解答

推荐使用什么格式和尺寸的源图像？

我们推荐使用 PNG 格式的图像作为源图像，尺寸最好为 1024×1024 像素或更高（例如 2048×2048）。源图像应该是正方形的，具有透明背景，以确保生成的图标在各种背景下都能良好显示。

iconsize 支持哪些平台的图标生成？

iconsize 支持多个主流平台的图标生成，包括：iOS（应用图标、App Store 图标）、Android（应用图标、自适应图标）、macOS（应用图标、文档图标）、Windows（应用图标、磁贴图标）、watchOS（应用图标、通知图标）、网页图标（favicon、PWA 图标）等。

如何将生成的图标集成到我的项目中？

iconsize 生成的图标按平台和尺寸组织成文件夹结构。您只需将相应平台的图标文件复制到项目中的正确位置即可。例如，对于 iOS 应用，将生成的图标添加到 Assets.xcassets 的 AppIcon 集合中；对于 Android 应用，将图标放置在相应的 mipmap 文件夹中。

iconsize 是否支持批量处理多个图标？

目前桌面应用每次只能处理一个图标。我们计划在未来版本中添加批量处理功能，敬请期待。

使用 iconsize 是否需要联网？

不需要。iconsize 的桌面应用是本地运行的，不需要互联网连接。所有图像处理都在您的设备上完成，不会上传到任何服务器，保证了您的图像资源安全。

iconsize 是免费使用的吗？

是的，iconsize 是一个开源项目，基于 Apache 2.0 许可证发布。您可以免费使用 iconsize 的所有功能，无论是个人项目还是商业项目。
