多平台应用图标生成工具。

Icon Gen 用于把一张高质量图标快速生成 iOS、Android、macOS、Windows、watchOS 所需的多尺寸资源和标准目录结构。它是 lys Open Source 体系中的项目资产生成工具。

项目能力

覆盖应用发布前最常见的图标资产准备工作，重点是本地处理、结构化输出和跨平台规格统一。

多平台规格

支持 iOS、iPadOS、macOS、watchOS、Android 和 Windows 常用图标尺寸。

标准目录结构

可生成 Xcode 需要的 AppIcon.appiconset 和 Android 资源目录结构。

浏览器本地处理

Web 版使用 Canvas 在浏览器内处理图片，不上传原图，适合快速生成和临时处理。

使用入口

当前项目包含 Web 版和 Electron 桌面版。线上主入口是项目站，在线工具作为体验入口保留。

F032 桌面版（Electron）差异说明 · 以差异说明覆盖

桌面壳不在浏览器原型范围（PRD §6 限定），其能力与差异以本卡覆盖（来源：reverse-analysis ②⑨、product-review C-4）：

桌面版独有能力（web 版无）

  • 导出到本地文件夹（目录选择）、打开输出文件夹
  • electron-store 配置持久化（selectedPlatforms / lastOutputPath）
  • 原生菜单（打开图片 Cmd+O / 导出 Cmd+E / 关于）、紧凑/展开双窗口尺寸
  • nativeImage 系统级生成（与 web Canvas 等价）

已知差异 / bug（旧版如实记录）

  • createContentsJson 选项不生效（取消勾选仍生成 Contents.json；main.js:315-339 未转发参数）——若桌面壳保留，V1 桌面版必须修复
  • 模板差异：desktop Windows 无 24×24；watchOS 多 66×66/40×40、少 87×87/80×80
  • 帮助菜单 GitHub 链接为占位死链（yourusername/icon-generator）
  • 品牌仍为 iconsize（与 web 的 Icon Gen 不一致）
