## 9. 非阻断备注

1. favicon.ico 404 为临时服务环境噪音（与 v0 验收一致），file:// 直开不受影响。
2. JSZip 在原型中为模拟打包层（零依赖约束）；真实 ZIP 生成与构建期内置为 P7 架构项（tech-architecture ADR-2）。
3. 二进制图片资产（iconsize.jpg/gif/截图）以占位块+来源标注呈现（ASSETS.md §3 约束）。
4. PAGE003 演示 GIF 占位、旧品牌 iconsize 照旧展示（品牌统一属 C-5 待决策）。
5. 旧版「重置不重置平台/选项勾选」行为照旧保留（page-spec 补充条目）；V1 结果区在选项变化时会即时重绘展示层（与旧版静默不变不同，属 B/FN-09 落地的展示增强，已在黄条文案中告知）。
