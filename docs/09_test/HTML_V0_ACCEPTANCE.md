## 5. 非阻断备注

1. 实测时浏览器默认请求 favicon.ico 返回 404（服务器目录无该文件），属临时服务环境噪音，与原型无关；file:// 直开不受影响。
2. 原型对旧版外链（GitHub/Gitee/Open/Gitee releases 等）统一「拦截+toast 提示旧目标」，满足零外链要求；旧版死链（页脚法律信息等）以提示语如实保留并标注。
3. PAGE003 演示 GIF/截图/品牌 logo 用占位块替代（原图标为二进制资源，不嵌入单文件原型）；PAGE002 预览图为 CSS 渐变占位。
4. JSZip 打包在原型中为「内容清单模拟」，未生成真实二进制 ZIP——符合原型零依赖约束；清单规则与 fileUtils.js 逐路径一致并经数值对账。
5. 桌面版（Electron，F032）不在浏览器原型范围；其能力差异已在逆向报告②⑨说明。
